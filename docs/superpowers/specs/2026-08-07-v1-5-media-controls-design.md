# LoudnessPlayer v1.5.0 设计说明

## 目标

在不创建音频转换副本、尽量不增加安装包体积的前提下，扩展本地音乐库格式支持，提供锁屏媒体控制、个人文件夹范围播放、棕色主题，并缩短整库响度校验时间。

## 范围

- 新增 M4A、AAC、OGG、Opus、WMA 的导入、一键扫描、文件夹扫描、搜索、去重、播放和响度校验。
- 新增暖棕色主题，放在既有侧边栏主题选择中并持久化。
- 采用 Media3 `MediaSessionService` 前台播放服务，使系统锁屏媒体卡片显示曲目信息、播放/暂停、上一首、下一首和停止；不使用无法可靠穿透锁屏的普通悬浮窗。
- 当用户从应用内个人文件夹开始播放时，播放队列只包含该文件夹的歌曲；顺序、随机和循环均不越过该范围。
- 响度校验使用最多两个受控并发任务，保留已完成结果并在用户停止或关闭校验时取消未完成任务。
- 发布版本为 `1.5.0`，`versionCode` 递增；继续使用 v1.4.0 建立的固定发布签名。

## 格式与解码策略

| 格式 | 导入识别 | 播放 | 响度校验 |
| --- | --- | --- | --- |
| M4A | 扩展名和 `audio/mp4` MIME | Media3 | Android 解码优先，失败后 FFmpeg |
| AAC | `.aac` 与 ADTS MIME | Media3 | Android 解码优先，失败后 FFmpeg |
| OGG | `.ogg` 与 Ogg MIME | Media3 | Android 解码优先，失败后 FFmpeg |
| Opus | `.opus` 与 Opus MIME | Media3；平台不能解码时 FFmpeg PCM 流 | Android 解码优先，失败后 FFmpeg |
| WMA | `.wma` 与 ASF/WMA MIME | FFmpeg PCM 流 | FFmpeg |

现有 FFmpeg 二进制是唯一新增格式的回退解码器，不加入新的大型解码依赖。所有 FFmpeg 流都必须先取得有限时长，再写入有限长度 WAV 头，避免重现 APE 的超长静音尾部问题。

## 播放服务与锁屏卡片

播放器实例从 ViewModel 移入 `MediaSessionService`。服务持有 ExoPlayer 与 MediaSession；界面通过 MediaController 读取状态和发送播放命令。服务播放期间以前台服务运行，系统通知和锁屏使用 MediaStyle 卡片。卡片显示内嵌封面；无封面时显示应用封面；操作为循环模式、上一首、播放/暂停、下一首和停止。

锁屏是否展示专辑封面、紧凑布局和某些按钮由设备 System UI 决定；核心的上一首、播放/暂停、下一首和停止命令必须可用。

## 个人文件夹范围

`PlayerUiState` 保存可选的 `activeFolderId`。打开并播放个人文件夹时，该 ID 设为当前文件夹；队列仅由其 `trackIds` 中仍存在的曲目生成。回到“全部歌曲”、歌手分类或智能分类后清除该 ID 并恢复全库队列。单曲循环重复当前曲；顺序和随机只在当前队列中前进。

## 响度性能与可靠性

校验队列按导入顺序处理，最多并行两首。每次结果完成即写入持久化存储并刷新 UI。Android `LoudnessAnalyzer` 失败时，对 M4A/AAC/OGG/Opus 使用通用 FFmpeg EBU R128 回退；WMA 直接走该路径。错误信息保留格式和 FFmpeg 的关键失败原因。并发任务在关闭统一响度、删除歌曲、或 ViewModel 清理时取消。

## 棕色主题

棕色主题使用低饱和胡桃棕主色、燕麦米背景和深可可文字；浅色对比度与现有绿色、蓝色主题一致。主题项名称为“棕色”，与浅色、深色、绿色、蓝色一起出现在侧边栏，并沿用当前偏好设置保存方式。

## 验收标准

- 五种新增格式均能被单文件、目录和 MediaStore 扫描识别，并显示正确格式徽标。
- M4A、AAC、OGG、Opus、WMA 可播放；平台解码失败时回退路径不生成持久化音频副本。
- 五种格式都能获得响度结果或显示明确的格式/解码失败原因。
- 锁屏时系统媒体卡片可控制上一首、播放/暂停、下一首和停止。
- 从个人文件夹播放时，所有播放模式都不跳出该文件夹。
- 同时运行的响度校验任务不超过两个；已完成歌曲不重复分析。
- 棕色主题可选择、重启后仍保持。
- v1.5.0 可覆盖 v1.4.0 安装并保留已有应用数据。
